# webhook-trigger-extension

웹페이지에서 선택한 텍스트나 현재 페이지 정보를 내가 지정한 웹훅 주소로 보내는 크롬 확장 프로그램입니다.
웹훅 주소만 있으면 어떤 서버나 자동화 도구와도 연결할 수 있습니다.

## 기능

- 텍스트를 드래그하고 우클릭 → "선택 텍스트를 웹훅으로 전송"
- 빈 곳에서 우클릭 → "현재 페이지 URL/제목을 웹훅으로 전송"
- 페이지에 특정 키워드("할인", "품절임박", "가격인하")가 보이면 자동 전송
- 30분마다 자동으로 확인 신호 전송 (팝업에서 켜고 끌 수 있음)
- 전송 결과는 아이콘 배지로 표시 (✓ 성공, ✗ 실패, ! 주소 미설정)

## 설치 방법 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 입력 후 Enter
2. 오른쪽 위 **개발자 모드** 스위치 켜기
3. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`manifest.json`이 들어 있는 폴더) 선택
5. 주소창 오른쪽 퍼즐 아이콘 → 이 확장 프로그램 핀 고정

## 사용 방법

1. 확장 프로그램 아이콘 클릭 → 웹훅 주소 입력 → **저장**
2. **테스트 전송**으로 연결 확인
3. 아무 페이지에서 텍스트를 선택하고 우클릭

## 전송되는 데이터 (JSON, POST)

```json
{
  "type": "selection",
  "text": "선택한 텍스트",
  "pageUrl": "https://example.com/page",
  "timestamp": "2026-10-28T12:00:00.000Z"
}
```

`type` 값은 `selection`, `page`, `auto`, `periodic-ping`, `test` 중 하나입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 설정과 권한 (Manifest V3) |
| `background.js` | 우클릭 메뉴, 웹훅 전송, 30분 알람 |
| `content.js` | 페이지 안에서 키워드 감지 |
| `popup.html` / `popup.js` | 웹훅 주소 설정 화면 |

## 참고

- 웹훅 주소는 `chrome.storage.sync`에 저장되어 같은 구글 계정의 다른 기기와 동기화됩니다.
- 키워드 목록은 `content.js` 맨 위 `KEYWORDS`에서 바꿀 수 있습니다.
- 스토어 등록 전에는 `host_permissions`의 `<all_urls>`를 꼭 필요한 사이트로 좁히는 것이 좋습니다.
